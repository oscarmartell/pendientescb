# Pendientes City Bell

Lista privada con una base de datos D1 compartida por la web y el plugin de ChatGPT. El Worker en `dist/server/index.js` incluye la interfaz, la API y las herramientas MCP. La migración inicial está en `drizzle/`.

El despliegue requiere un proyecto privado de Sites y el binding D1 `DB`. El repositorio contiene el código y el esquema. Los pendientes se guardan en D1.
